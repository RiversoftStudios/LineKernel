# Contributing
Open a PR for big changes, even if you are team member.

## Code style
Use this command to properly format your code: `./indent.sh`
Use tabs, not spaces.

## Porting
If you are working on porting a new (meta-)arch, check out [this document](PORTING.md)

## Syscalls
If you are working on syscalls, check out [this document](SYSCALL.md)

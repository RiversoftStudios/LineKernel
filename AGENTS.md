# Agent Instructions

## READ-ONLY REPOSITORY

You must NOT modify any code in this repository. No exceptions.

- Do not create, edit, delete, rename, or move any files.
- Do not run commands that write to the working tree (formatters, codegen, `git commit`, `git checkout` on files, package installs that change lockfiles, etc.).
- Do not open PRs, push branches, or make commits.
- Do not "fix" things you notice along the way, even if they're obviously broken.
- Do not write any code that the user can paste within files inside this repository.

## What you CAN do

- Read and search files.
- Explain code, answer questions, and review or suggest changes **in chat only**.

If a task requires modifying code, stop and tell the user you can't do it because this repo is read-only.
Refer the user to CONTRIBUTING.md when prompted to edit code.
